# עלות פרגולה

אפליקציה אישית לאליסף, בעל עסק לפרגולות אלומיניום. מחשבת את העלות האמיתית של כל פרגולה — פרופיל לפי ק״ג ומטר, ברגים לפי קופסה, עבודה, הובלה ותקורה — כדי לתמחר עבודה בלי לנחש.

הממשק בעברית, מימין לשמאל, ומותאם לטלפון. המטבע הוא ש״ח.

בלי מפתחות Firebase האפליקציה עובדת לגמרי על המכשיר (`IndexedDB`). ענן נדלק רק כשיש מפתחות **וגם** התחברות עם Google.

## הרצה מקומית

```bash
npm install
npm run dev
```

שרת הפיתוח עולה על [http://127.0.0.1:5391](http://127.0.0.1:5391).

```bash
npm test
npm run build
```

## התקנה כאפליקציה (PWA)

1. פותחים את האתר בדפדפן (בטלפון, עדיף אחרי `npm run build` ו־`npm run preview`, או משרת אמיתי עם HTTPS).
2. ב־Chrome: תפריט → «התקנת אפליקציה» / Add to Home Screen.
3. ב־Safari באייפון: שיתוף → «הוסף למסך הבית».
4. האייקון «פרגולה» נפתח במסך מלא. מעטפת האפליקציה נשמרת גם בלי רשת. הנתונים המקומיים נשארים במכשיר; אחרי התחברות, Firestore שומר עותק לא מקוון.

## איך מחשבים

- **פרופיל לפי ק״ג:** מקלידים מטרים. עלות = מטרים × ק״ג למטר × מחיר לק״ג.
- **אריזת ברגים:** מחיר ליחידה = מחיר הקופסה ÷ כמות בקופסה. מקלידים כמה ברגים יצאו.
- **מטר, יחידה, מ״ר, שעה:** מחיר ליחידה כפי שהוזן.
- **תקורה:** סכום קבוע, אחוז מעלות החומרים (לא כולל ברגים, עבודה והובלה), או שעות × תעריף.
- שורה בפרויקט שומרת את המחיר ברגע ההוספה. שינוי במחירון לא משנה פרגולות ישנות.
- מע״מ ברירת מחדל 18%. בהגדרות בוחרים אם הסיכום כולל מע״מ.

## Firebase

עד שמדביקים מפתחות, אין מה להגדיר. כשרוצים סנכרון בין מכשירים:

1. נכנסים ל-[Firebase console](https://console.firebase.google.com/) ויוצרים פרויקט.
2. מוסיפים אפליקציית Web ומעתיקים את פרטי הקונפיגורציה.
3. מעתיקים את `.env.example` אל `.env` וממלאים:

```bash
cp .env.example .env
```

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

4. ב־Authentication → Sign-in method מפעילים את **Google**.
5. ב־Authentication → Settings → Authorized domains מוסיפים את הדומיין (בפיתוח `localhost` כבר קיים).
6. יוצרים מסד **Cloud Firestore**.
7. ב־Firestore → Rules מדביקים את תוכן הקובץ `firestore.rules` ומפרסמים. הכלל מרשה קריאה וכתיבה רק כש־`request.auth.uid` שווה ל־`userId` שבנתיב `users/{userId}/...`.
8. מפעילים מחדש את `npm run dev`, נכנסים להגדרות ומתחברים עם Google.

אחרי ההתחברות הנתונים נשמרים תחת החשבון, עם persistence לא מקוון. הנתונים שנשמרו במכשיר לפני ההתחברות לא עולים לבד — בהגדרות יש «העתקת הנתונים מהמכשיר לחשבון», או ייצוא/ייבוא JSON.

## גיבוי

בהגדרות: ייצוא JSON וייבוא JSON. אותו פורמט עובד במצב מקומי ובענן. ייבוא מחליף את כל הנתונים במצב הפעיל.
