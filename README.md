# עלות פרגולה

אפליקציה אישית לאליסף, בעל עסק לפרגולות אלומיניום. מחשבת את העלות האמיתית של כל פרגולה — פרופיל לפי ק״ג ומטר, ברגים לפי קופסה, עבודה, הובלה ותקורה — כדי לתמחר עבודה בלי לנחש.

הממשק בעברית, מימין לשמאל, ומותאם לטלפון. המטבע הוא ש״ח.

יש שני מסדים נפרדים לגמרי:

- **פיתוח** (`npm run dev`): מסד מקומי בלבד, בתיקייה `data/dev`. לא צריך Docker. המצב הזה לא פותח כתובת של Neon. אם `DATABASE_URL` מצביע על `neon.tech`, השרת מסרב לעלות ואומר שמצב פיתוח לא נוגע בייצור.
- **ייצור** (`npm start`): Neon Postgres בלבד, דרך `DATABASE_URL` בצד השרת. בלי מחרוזת חיבור, או אם היא מצביעה על localhost, השרת מסרב לעלות. מחרוזת הייצור לא נשמרת בגיט.

## הרצה מקומית

```bash
npm install
npm run dev
```

שרת הפיתוח עולה על [http://127.0.0.1:5391](http://127.0.0.1:5391). הנתונים נשמרים ב־`data/dev` ונשארים במחשב הזה.

```bash
npm test
npm run build
```

## ייצור

מעתיקים את `.env.example` אל `.env.production` (הקובץ ב־gitignore) וממלאים את מחרוזת החיבור של Neon. אפשר גם להגדיר את המשתנים ישירות בסביבת השרת. `DATABASE_URL` קיים בייצור בלבד.

```bash
npm run build
npm start
```

`npm start` יוצר את הטבלאות בהפעלה אם הן חסרות, וזורע את מחירון הפתיחה רק כשהמסד ריק. סיסמה אופציונלית `APP_PASSWORD` נאכפת רק בייצור. בפיתוח על localhost אין צורך בסיסמה.

## התקנה כאפליקציה (PWA)

1. פותחים את האתר בדפדפן אחרי `npm run build` ו־`npm start`, או משרת אמיתי עם HTTPS.
2. ב־Chrome: תפריט ← «התקנת אפליקציה».
3. ב־Safari באייפון: שיתוף ← «הוסף למסך הבית».
4. האייקון «פרגולה» נפתח במסך מלא. מעטפת האפליקציה יכולה להישמר במכשיר. הנתונים עצמם נשארים בשרת: במסד המקומי בפיתוח, או ב־Neon בייצור.

## איך מחשבים

- **פרופיל לפי ק״ג:** מקלידים מטרים. עלות = מטרים × ק״ג למטר × מחיר לק״ג.
- **אריזת ברגים:** מחיר ליחידה = מחיר הקופסה ÷ כמות בקופסה. מקלידים כמה ברגים יצאו.
- **מטר, יחידה, מ״ר, שעה:** מחיר ליחידה כפי שהוזן.
- **תקורה:** סכום קבוע, אחוז מעלות החומרים (לא כולל ברגים, עבודה והובלה), או שעות × תעריף.
- שורה בפרויקט שומרת את המחיר ברגע ההוספה. שינוי במחירון לא משנה פרגולות ישנות.
- מע״מ ברירת מחדל 18%. בהגדרות בוחרים אם הסיכום כולל מע״מ.
